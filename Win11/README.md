# Windows 11

Espacio reservado para implementaciones diseñadas y validadas específicamente en Windows 11.

**Estado:** estructura inicial; todavía no hay scripts publicados en esta carpeta.

No copiar ni ejecutar automáticamente los scripts de `Win10/` en Windows 11. Antes de publicar un perfil aquí se deben comprobar, como mínimo:

- Versión y build de Windows 11 admitidas.
- Disponibilidad y comportamiento de los cmdlets SMB.
- Compatibilidad de las políticas NTLM y sus valores de registro.
- Canales e identificadores de eventos disponibles.
- Comportamiento de las reglas de Windows Defender Firewall.
- Requisitos de reversión y compatibilidad con dispositivos de red.
